# 赛知行 · 规则有据，行动有序

校园竞赛规则解读与材料预检Web应用：导入通知、检索证据、审阅规则、核对条件、比较冲突、生成清单。

参赛学校：广州商学院。团队：WEB玩家，B组。成员：罗锦豪、叶钧锴、庄金源。指导教师：谭永恒。

## 安装运行

要求Node.js 22.2或更高版本、pnpm，依赖以锁文件为准。先在PowerShell中进入项目目录（包含package.json），再运行以下命令。

```powershell
pnpm install --frozen-lockfile
Copy-Item .env.example .env.local
# 默认AI_ENABLED=false，无需Key。不要提交真实密钥。
pnpm dev
```

访问终端打印的本地地址。默认无Key降级模式：问答仅返回检索原文，规则用本地解析器；资料、条件核对、冲突提示、材料预检和清单均可使用。无需创建.env.local，也不会向外部模型发送资料。

可选模型增强：在本机.env.local中设置AI_ENABLED=true并填写自己的DEEPSEEK_API_KEY，重启后才启用；MODEL_ID默认deepseek-chat，可选DEEPSEEK_BASE_URL。聊天和规则提取共用配置。即使环境中存在密钥，只要没有显式启用也不调用模型。模型调用会产生供应商费用；不要把密钥提交给GitHub。

```powershell
pnpm verify
pnpm start --hostname 127.0.0.1 --port 3002
```

不要让开发服务与生产构建同时使用同一`.next`目录。PDF worker由predev/prebuild复制，不依赖外部CDN。

## 功能与边界

- 赛事工作区隔离保存，文档记录年份、阶段、组别、来源及替代关系；元数据需要用户确认，不能从导入时间推断发布日期。
- TXT/Markdown≤2MB，文本PDF≤10MB且≤100页；每个工作区≤20份文档、30万字。保留PDF页码与文本字符位置，扫描、加密及明显乱码PDF会拒绝，不支持OCR。
- DeepSeek提取结构化规则，检查摘录确实存在后供用户修正和确认；单次AI分析≤4万字。无模型时使用本地解析器，不完整覆盖任意写法和例外条件。
- 人数、组别辅助核对；同年份、阶段、组别、条件的奖项比例、日期、人数冲突提示。信息缺失或冲突不认定通过，明确确认的替代关系使旧版本退出比较。
- 中文BM25式词法检索，无embedding或向量数据库。Function Calling工具包括检索、规则比较、条件核对、清单生成，最多4步；显示真实执行记录。
- 最终事实使用逐字原文摘录，检查引用ID和摘录包含关系；不是任意转述的语义验证。校验失败回退原文卡片，事实与固定辅助建议分开。
- 材料清单去重、可选标记、自查勾选和Markdown导出。条款变化使旧状态失效；勾选不是官方审核。
- 实际预检只检查README章节关键词、PDF页数、视频元数据。本赛事演示阈值为PDF≤30页、MP4为300—480秒且≥1920×1080；不检查代码质量、讲解内容和视频音轨。

## 技术架构与接口

Next.js 15 / React 19 / TypeScript / Tailwind / AI SDK 4 / DeepSeek / PDF.js / Zod。

```text
浏览器：工作区原文 → 文本/PDF解析 → 来源、版本、页码与字符位置
API：快照校验 → 检索与受限工具 → 原文摘录校验 → 证据回答
浏览器：规则审阅 → 条件核对 → 清单及实际材料预检
```

`POST /api/chat`接收工作区ID、阶段、画像、文档快照、消息ID与问题；返回AI SDK数据流中的工具记录、证据映射、校验结果及回答。引用按消息ID关联。

`POST /api/analyze`接收同类快照，返回提取规则、拒绝条数及模型/本地模式；结果仍需人工审阅。

核心代码：`lib/rules.ts`、`lib/snapshot.ts`、`lib/answer.ts`、`lib/workspace-store.ts`；界面业务组件在`app/components/CompetitionPanels.tsx`。

## 隐私、迁移与适用范围

原文保存在当前浏览器，不跨设备同步。问答发送问题、必要画像和证据；AI规则分析发送当前赛事原文至DeepSeek。密钥仅从服务端环境变量读取；不记录完整原文或密钥。API限制请求大小、并发、频率和超时。

IndexedDB从v1迁移到v2，旧`current`键留作备份，新数据写`library-v2`。迁移失败不删除旧数据。不同端口属于不同浏览器源，资料不共享。

快照校验保证一致性，不证明来源经过官方认证。当前是本地交付，无多人身份认证、跨实例限流或可信云端知识库；不作为公网生产服务。不会自动报名、缴费或提交，不代替组委会资格认定。

演示摘录来自用户提供文本，未经官网核验；独立合成测试通知明确标注，不冒充官方资料。测试、模型对比和修复复测均在`submission/evaluation/`，未开展的用户试用不生成结果。
