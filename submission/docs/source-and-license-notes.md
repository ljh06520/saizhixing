# 数据来源与第三方技术说明

## 数据来源

1. 演示摘录来源于用户提供的《全国高校AI Web开发挑战赛》介绍文本，未经官网核验。文字中的赛事时间、奖项比例和报名规则仅用于演示与核对，不作为官方有效性声明。
2. 独立测试通知由开发过程编写，用于验证人数边界、组别、版本、冲突和拒答等行为。测试数据应明确标注为合成资料，不冒充真实赛事。
3. 用户自行导入的文件由用户负责确认使用权限。系统不自动获得其他赛事网站的内容使用授权。
